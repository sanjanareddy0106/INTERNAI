How the scoring works

Match Score (0–100) = Skills + Domain + Location + Academic

Skills (max 50) = 50 × (matched required skills ÷ total required skills), after normalising case, spaces and synonyms.


Domain (max 25) = 25 if the internship domain equals the preferred domain, otherwise 0.


Location (max 15) = 15 if same city or the internship is Remote; 7.5 for a different city; 7.5 if the student prefers Remote but the role is on-site.


Academic (max 10) = 10 if the branch is listed for the internship; 5 for a related branch group; otherwise 0.

Weights are defined in one place (W) in the code and can be tuned.

Important: The current prototype uses sample internship records and rule-based matching. It does not fetch real-time vacancies, verify company listings, or submit applications. The score explains how closely a sample role matches the profile; it is not a hiring probability.
